HOME STRENGTH TRACKER

Files:
- index.html
- style.css
- app.js
- data.json
- photos/   <- save your progress photos here if you want them bundled with the project

How to use:
1. Put all files in one folder.
2. Open index.html in a browser.
3. For phone use, you can host the folder on GitHub Pages or another static host and add the site to your home screen.
4. The tracker saves workout logs/check-ins in the browser's localStorage.
5. data.json is a blank export/template; the app does not directly overwrite it because normal browser JavaScript cannot safely write arbitrary files.

Workout rules:
- 4 strength days: Mon, Tue, Thu, Fri.
- Wednesday/Saturday: walking/cardio.
- Sunday: rest.
- Most strength workouts: 45–60 minutes.
- Stop most sets with about 1–3 clean reps left.
- Progress reps first, then make an exercise harder or add a little backpack weight.
- Do not train through dizziness/near-blackout.
